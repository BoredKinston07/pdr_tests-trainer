# Тренажер ПДР (категорія B1/B за замовчуванням)

Запуск: `python3 -m http.server 8000` у цій папці → http://localhost:8000
(або залий папку на GitHub Pages / Netlify — працюватиме з телефона).

Дані: `data/questions.json` (питання), `data/answers.json` (ключ), `img/` (картинки).
Після зміни даних: `python3 build.py` → оновить `data.js`.
Ключ відповідей є для розділів 1–47 (категорії A1/A, B1/B). Розділи 48+ (C, D, E, T) без ключа.
